# THE SARTORIALIST CLUB — сайт-визитка

Статический сайт для публикации на GitHub Pages. Без корзины, цен, размеров, выдуманных характеристик и отзывов. Основное действие — переход в профиль Авито.

## Что уже настроено

- Адаптивная вёрстка для компьютера и телефона.
- Палитра брендбука: тёмно-зелёный, молочный, приглушённое золото.
- Структура по мотивам референса Sartorialista Amsterdam: имиджевый первый экран, навигация, фотографии, отдельный блок перехода к предложениям.
- Ссылка на профиль Авито.
- Ссылка на исходную фотогалерею.
- Переключатель источника каталога в `assets/js/config.js`.

## Фотографии

В переданной онлайн-галерее при просмотре удалось получить одно изображение — крупный план ткани и пуговиц костюма. Оно используется как редакционный визуал и загружается с хостинга фотогалереи. Кнопка «Открыть фотогалерею» ведёт на полный альбом.

Когда будут доступны остальные фотографии, их можно положить в `assets/images/` и добавить в массив `PHOTO_ITEMS` в `assets/js/config.js`. Для независимости от внешней галереи лучше использовать локальные изображения.

## Как переключить источник каталога

Откройте `assets/js/config.js` и поменяйте одну строку:

```js
export const CATALOG_SOURCE = "photos";
```

На:

```js
export const CATALOG_SOURCE = "avito";
```

Сейчас режим `photos` включён. При переключении на `avito` страница попробует загрузить JSON-массив объявлений из `SITE_CONFIG.avitoFeedUrl`. Если endpoint ещё не указан, сайт покажет только переход в профиль Авито. Для карточек используются только фотографии, названия и ссылки — цены и размеры не выводятся.

**Безопасность:** GitHub Pages — статический хостинг. Нельзя помещать `client_secret` Авито в JavaScript, HTML или публичный репозиторий. Для автоматической загрузки объявлений потребуется отдельный backend/serverless endpoint, который хранит секрет и отдаёт сайту только публичные данные объявлений.

## Публикация на GitHub Pages

1. Создайте новый GitHub-репозиторий.
2. Загрузите в корень репозитория содержимое этой папки: `index.html`, `assets/`, `README_RU.md`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. Через некоторое время GitHub покажет адрес опубликованного сайта в разделе Pages.

Сайт использует относительные пути, поэтому подходит и для адреса вида `username.github.io/repository/`.
