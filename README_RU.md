# THE SARTORIALIST CLUB — README_RU

Основная документация находится в [README.md](README.md).

Кратко:

- Одностраничный редакционный лендинг для GitHub Pages.
- Палитра и шрифты сохранены по брендбуку.
- Фотографии локальные, в `assets/images/` (WebP, два размера через `srcset`).
- Настройки ссылок — в `assets/js/config.js` (`phone`, `avitoProfileUrl`, `galleryUrl`).
- Раздел «Референсы»: 24 фотографии костюмов, часть лотов уже продана; карточки ведут в профиль Авито.
- В разделе «О магазине» — профиль Максима: подход, сервис, образование и опыт.
- Синхронизации с Авито и автоподтягивания цен нет.
- Цены, размеры, отзывы, рейтинги и неподтверждённые сведения не добавлены.
- Публикация: **Settings → Pages → Deploy from a branch → main → / (root)**.
