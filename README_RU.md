# THE SARTORIALIST CLUB — сайт-визитка

Статический сайт для публикации на GitHub Pages. Основная задача — показать фотографии мужских костюмов и перевести посетителя в профиль Авито.

## Что находится в проекте

- Адаптивная вёрстка для компьютера и телефона.
- Палитра брендбука: тёмно-зелёный, молочный, приглушённое золото.
- Структура по мотивам Sartorialista Amsterdam: имиджевый первый экран, каталог фотографий, редакционная фотогалерея, переход на Авито.
- 20 локальных фотографий в `assets/images/` в формате WebP.
- Карточки костюмов ведут в профиль Авито.
- Цены, размеры, характеристики, отзывы и неподтверждённые сведения не добавлены.

## Фотографии

Фотографии выбраны из переданного архива и сохранены непосредственно в проекте:
- 12 фотографий костюмов для каталога;
- 4 фотографии деталей ткани и отделки;
- 3 фотографии пространства и образа;
- 1 отдельная фотография для главного экрана.

Изображения оптимизированы в WebP и хранятся в `assets/images/`. Внешние ссылки на фотогалерею для отображения изображений больше не используются.

## Переключение источника каталога

Откройте `assets/js/config.js` и найдите:

```js
export const CATALOG_SOURCE = "photos";
```

Варианты:
- `"photos"` — локальные фотографии (текущий режим);
- `"avito"` — загрузка объявлений из JSON endpoint.

Для включения Авито API нужно заполнить `SITE_CONFIG.avitoFeedUrl` адресом защищённого backend endpoint. GitHub Pages — статический хостинг, поэтому `client_secret` Авито нельзя помещать в JavaScript, HTML или публичный репозиторий.

Ожидаемый формат JSON endpoint:

```json
[
  {
    "title": "Мужской костюм",
    "image": "https://example.com/photo.webp",
    "url": "https://www.avito.ru/..."
  }
]
```

## Публикация на GitHub Pages

1. Создайте GitHub-репозиторий.
2. Загрузите в корень репозитория всё содержимое папки `sartorialist_site_updated`: `index.html`, `assets/`, `404.html`, `README_RU.md`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. Через некоторое время GitHub покажет адрес опубликованного сайта в разделе Pages.

Все пути к изображениям относительные, поэтому сайт работает на GitHub Pages и в корневом домене пользователя.
