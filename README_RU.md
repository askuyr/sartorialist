# THE SARTORIALIST CLUB — сайт-визитка

Статический адаптивный сайт для GitHub Pages. Структура переработана по присланному референсу, визуальная палитра сохранена по брендбуку THE SARTORIALIST CLUB.

## Структура страницы

1. Компактная шапка и навигация.
2. Большой имиджевый первый экран с фотографией и переходом на Авито.
3. Четыре навигационные карточки.
4. Блок о магазине с фотографией.
5. Фотокаталог костюмов.
6. Асимметричная сетка фотографий и текстовых блоков о деталях.
7. Финальный переход в профиль Авито.

## Контент

- Фотографии хранятся локально в `assets/images/`.
- Внешние ссылки на изображения не используются.
- Не добавлены цены, размеры, отзывы, рейтинги, выдуманные показатели и неподтверждённые характеристики.
- Кнопки каталога ведут в профиль Авито.

## Переключение источника каталога

Откройте `assets/js/config.js`:

```js
export const CATALOG_SOURCE = "photos";
```

- `"photos"` — локальные фотографии, включено сейчас.
- `"avito"` — загрузка объявлений из JSON endpoint после подключения backend.

Для интеграции Авито нужно заполнить `SITE_CONFIG.avitoFeedUrl` адресом защищённого endpoint. Не храните `client_secret` в GitHub Pages или frontend-коде.

## Публикация на GitHub Pages

Загрузите всё содержимое этой папки в корень репозитория: `index.html`, `assets/`, `404.html`, `README_RU.md`. Затем откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
