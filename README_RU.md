# THE SARTORIALIST CLUB — версия 3

Редизайн сайта-визитки в эстетике брендбука и по композиции предоставленного референса.

- Локальные фотографии находятся в `assets/images/`.
- Каталог работает в режиме `photos` по умолчанию.
- Переключатель `photos / avito` находится в `assets/js/config.js`.
- Все ссылки на Авито ведут в профиль магазина.
- Цены, размеры, отзывы, рейтинги и неподтверждённые сведения не добавлены.

## Публикация
Загрузите содержимое архива в корень репозитория GitHub Pages, заменив прежние `index.html`, `assets/` и `README_RU.md`. Затем проверьте **Settings → Pages**.

## Важно для GitHub Pages
Пути к файлам относительные. Секретные ключи Авито нельзя помещать в публичный frontend; для интеграции понадобится отдельный backend endpoint.
