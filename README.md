# THE SARTORIALIST CLUB — сайт-визитка

Статический адаптивный сайт для GitHub Pages. Одностраничный редакционный лендинг: крупная типографика, полноэкранные фотографии, горизонтальная лента коллекции и асимметричные сетки. Палитра и шрифтовые семейства сохранены по брендбуку THE SARTORIALIST CLUB.

## Структура страницы

1. **Hero** — полноэкранное фото, крупный заголовок «Стиль в деталях» и гигантский фоновый вордмарк.
2. **Бегущая строка** — короткие фразы бренда между секциями.
3. **Две кампании** — сплит-панели «Для образа» и «Для деталей».
4. **Референсы** — горизонтальная лента из 24 фотографий костюмов с прокруткой, стрелками, drag и счётчиком. Это референсы, а не витрина: часть лотов уже продана, актуальные предложения — в профиле на Авито.
5. **О магазине** — текстовая колонка, асимметричная фотокомпозиция и блок профиля Максима с подходом к работе.
6. **Детали** — сетка крупных планов ткани и отделки с текстовыми вставками.
7. **Фотогалерея** — полноэкранный кадр с переходом во внешнюю галерею.
8. **Авито** — финальный призыв с круглой печатью.
9. **Подвал** — навигация, ссылки и крупный вордмарк.

## Структура репозитория

```
index.html            главная страница
404.html              страница ошибки в фирменном стиле
robots.txt            правила для поисковых систем
sitemap.xml           карта сайта
assets/
  css/styles.css      дизайн-система и адаптив
  js/config.js        ссылки и список референсов
  js/main.js          меню, скролл-эффекты, лента
  images/             фотографии (WebP, в двух размерах)
  favicon.svg         иконка сайта
```

## Дизайн и поведение

- Палитра: тёмно-зелёный, кремовый, золотой, шалфейный и чернильный.
- Типографика: антиква в стиле Bodoni + системный гротеск Helvetica/Arial. Новые веб-шрифты не подключены.
- Липкая шапка, полноэкранное мобильное меню, подсветка активного раздела при прокрутке.
- Появление блоков при скролле, hover-состояния, поддержка `prefers-reduced-motion`.
- Фотолента управляется стрелками, перетаскиванием, клавиатурой и тач-скроллом.
- Все изображения локальные, с `loading="lazy"` вне первого экрана и `srcset` для мелких экранов.
- Доступность: skip-link, `aria-current`, видимый фокус, контрастные подписи.

## Контент

- Фотографии хранятся локально в `assets/images/`.
- Внешние ссылки на изображения не используются.
- Не добавлены цены, размеры, отзывы, рейтинги, выдуманные показатели и неподтверждённые характеристики.
- Карточки каталога ведут в профиль Авито.
- Фотогалерея открывается по ссылке из `SITE_CONFIG.galleryUrl`.

## Настройка ссылок

Откройте `assets/js/config.js`:

```js
export const SITE_CONFIG = {
  phone: "+79312992222",
  avitoProfileUrl: "https://www.avito.ru/brands/i205036214",
  galleryUrl: "https://ellenutelle.gallery.photo/gallery/maksim-kostumy-14rmew/",
};
```

- `phone` — номер телефона для ссылок `tel:` (шапка, меню, контактный блок, подвал).
- `avitoProfileUrl` — профиль магазина, используется во всех кнопках и ссылках.
- `galleryUrl` — внешняя фотогалерея.

Каталог собирается вручную из локальных фотографий в `assets/images/` (список — в `assets/js/config.js`, `PHOTO_ITEMS`). Синхронизации с Авито и автоподтягивания цен нет: цены, размеры и наличие публикуются вручную, все карточки ведут в профиль магазина по ссылке `avitoProfileUrl`.

## Работа с изображениями

- Формат WebP, качество 80, без метаданных.
- Основной файл + уменьшенная копия (`-640`, `-900`, `-1200` и т. п.) подключается через `srcset`.
- Новое фото: положить в `assets/images/`, добавить запись в `PHOTO_ITEMS` и указать то же имя с суффиксом `-640` для малого варианта.
- `og-image.jpg` (1200×630) — превью для ссылок в соцсетях, генерируется из `hero-banner.webp`.

## Локальный просмотр

Откройте `index.html` в браузере или запустите простой сервер из корня репозитория:

```bash
python -m http.server 8000
```

## Публикация на GitHub Pages

Откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`. Сайт будет доступен по адресу `https://askuyr.github.io/sartorialist/`.
