# THE SARTORIALIST CLUB — сайт-визитка

Статический адаптивный сайт для GitHub Pages. Тёмный редакционный лендинг: один глубокий фон, подсвеченные фотографии, крупная антиква и индекс костюмов с живым превью. Палитра и характер бренда сохранены, шрифты размещены локально.

## Структура страницы

1. **Hero** — название, короткое описание, услуги, факты и стена из 14 костюмов.
2. **Избранный лот** — полноэкранный кадр и карточка графитового костюма.
3. **Лоты** — индекс из 24 названий: наведение или фокус показывает костюм в закреплённом превью; на телефоне у каждой строки миниатюра.
4. **Как проходит примерка** — три этапа с фотографиями по диагонали.
5. **О магазине** — факты, фотоплашка-буквица и текст Максима.
6. **В магазине** — шесть кадров с подписями.
7. **Вопросы** — открытые ответы, без аккордеона.
8. **Связаться** — телефон крупной строкой, адрес, часы и ссылки.
9. **Подвал** — фотография, навигация, вордмарк и юридический блок.

Отдельные страницы: `kostyumy.html`, `podbor.html`, `kontakty.html`, `privacy.html`, `404.html`.

## Структура репозитория

```
index.html            главная страница
kostyumy.html         костюмы из отбора
podbor.html           подбор костюма
kontakty.html         контакты
privacy.html          политика обработки персональных данных
404.html              страница ошибки
robots.txt            правила для поисковых систем
sitemap.xml           карта сайта
assets/
  css/fonts.css       @font-face для локальных шрифтов
  css/styles.css      дизайн-система и адаптив
  fonts/              Playfair Display и Jost (woff2, кириллица + латиница)
  js/config.js        ссылки и список лотов
  js/main.js          меню, появление блоков, индекс с превью
  images/             фотографии (WebP, в двух размерах)
  favicon.svg         иконка сайта
```

## Дизайн и поведение

- Палитра: глубокий зелёно-чёрный фон, поверхности на тон светлее, кремовый текст, бронзовый акцент.
- Типографика: Playfair Display для заголовков, Jost для текста. Оба шрифта локальные, с кириллицей.
- Нет градиентов, теней, тонких линий и декоративной нумерации: разделение только отступом и сменой тона.
- Липкая шапка без рамки, полноэкранное мобильное меню.
- Индекс лотов: наведение, фокус и клик меняют кадр в превью; на телефоне превью заменяется миниатюрами.
- Появление секций при скролле, hover-состояния, поддержка `prefers-reduced-motion`.
- Доступность: skip-link, видимый фокус, `aria-current`, alt у фотографий, контраст текста.

## Контент

- Фотографии хранятся локально в `assets/images/`.
- Внешние ссылки на изображения не используются.
- Не добавлены цены, размеры, отзывы, рейтинги, выдуманные показатели и неподтверждённые характеристики.
- Превью индекса и кнопки ведут в профиль Авито.
- Фотогалерея открывается по ссылке из `SITE_CONFIG.galleryUrl`.

## Настройка ссылок

Откройте `assets/js/config.js`:

```js
export const SITE_CONFIG = {
  phone: "+79312992222",
  avitoProfileUrl: "https://www.avito.ru/brands/i205036214",
  galleryUrl: "https://ellenutelle.gallery.photo/gallery/maksim-kostumy-14rmew/",
};
```

- `phone` — номер для ссылок `tel:` (шапка, меню, контакты, подвал).
- `avitoProfileUrl` — профиль магазина.
- `galleryUrl` — внешняя фотогалерея.

Каталог собирается вручную из локальных фотографий (`PHOTO_ITEMS` в `assets/js/config.js`). Синхронизации с Авито и автоподтягивания цен нет.

## Юридический блок

В подвале всех страниц: копирайт, оговорка о публичной оферте, цены в рублях, адрес, часы, телефон и ссылки на политику и сведения о продавце. `privacy.html` описывает обработку данных по 152-ФЗ. Реквизиты ИП (ФИО, ОГРНИП, ИНН) нужно добавить после подтверждения владельцем.

## Работа с изображениями

- Формат WebP, качество 80, без метаданных.
- Основной файл + уменьшенная копия (`-640`, `-900`, `-1200` и т. п.) подключается через `srcset`.
- Новое фото: положить в `assets/images/`, добавить запись в `PHOTO_ITEMS` и указать то же имя с суффиксом `-640`.
- `og-image.jpg` (1200×630) — превью для ссылок в соцсетях.

## Локальный просмотр

Откройте `index.html` в браузере или запустите сервер из корня репозитория:

```bash
python -m http.server 8000
```

## Публикация на GitHub Pages

**Settings → Pages → Deploy from a branch**, ветка `main`, папка `/ (root)`. Домен и HTTPS настраиваются в том же разделе.
