# THE SARTORIALIST CLUB — сайт-визитка

Статический адаптивный сайт для GitHub Pages. Светлый редакционный лендинг-галерея: костяной фон, лесной и бронзовый акценты, крупная антиква, фотографии как отпечатки на стене. Сайт показывает галерею, а лоты, цены и наличие остаются в профиле на Авито.

## Структура страницы

1. **Hero** — крупный заголовок, короткое описание, кнопка в галерею и фотография магазина.
2. **Бегущая строка** — короткие фразы бренда.
3. **Две кампании** — «Для образа» и «Для деталей» с подписями.
4. **Галерея** — 16 фотографий костюмов, собранных вокруг заголовка; при прокрутке отпечатки плавно смещаются, клик открывает фото крупно.
5. **Манифест** — цитата Максима на фоне фотографии.
6. **О магазине** — текст, фотокомпозиция и блок профиля.
7. **Детали** — крупные планы ткани, отделки и посадки с короткими заметками.
8. **Фотогалерея** — полноэкранный кадр с переходом во внешнюю галерею.
9. **Контакты** — телефон крупной строкой, адрес, часы и ссылки.
10. **Вопросы** — пять открытых ответов.
11. **Подвал** — навигация, ссылки, вордмарк и юридический блок.

Отдельные страницы: `kostyumy.html`, `podbor.html`, `kontakty.html`, `privacy.html`, `404.html`.

## Структура репозитория

```
index.html            главная страница
kostyumy.html         костюмы из отбора
podbor.html           подбор костюма
kontakty.html         контакты
privacy.html          политика обработки персональных данных
404.html              страница ошибки
robots.txt            правила для поисковых систем
sitemap.xml           карта сайта
assets/
  css/fonts.css       @font-face для локальных шрифтов
  css/styles.css      дизайн-система и адаптив
  fonts/              Playfair Display и Jost (woff2, кириллица + латиница)
  js/config.js        телефон и ссылки магазина
  js/main.js          меню, появление блоков, просмотр фото крупно
  images/             фотографии (WebP, в двух размерах)
  favicon.svg         иконка сайта
```

## Дизайн и поведение

- Палитра: костяной фон, лесной тёмно-зелёный, бронзовый акцент.
- Типографика: Playfair Display для заголовков, Jost для текста. Оба шрифта локальные, с кириллицей.
- Нет «бровей», декоративной нумерации, тонких линеек, теней и градиентов: разделение только отступом и сменой тона.
- Галерея: 16 кадров в четыре колонки, без обрезки — от портретов и деталей до зала магазина; на планшете три колонки, на телефоне две. Клик по кадру открывает его крупно в модальном окне (`<dialog>`), закрытие — Esc, крестик или клик по фону.
- Галерея встроена в `index.html` статически: фотографии видны поисковым системам и без JavaScript.
- Hero: шторка-раскрытие фотографии при первом появлении.
- Липкая шапка, полноэкранное мобильное меню, появление секций при скролле.
- Доступность: skip-link, видимый фокус, `aria-current`, alt у фотографий, контраст текста.

## Контент

- Фотографии хранятся локально в `assets/images/`.
- Внешние ссылки на изображения не используются.
- Не добавлены цены, размеры, отзывы, рейтинги, выдуманные показатели и неподтверждённые характеристики.
- Галерея показывает 16 фотографий, размеченных прямо в `index.html`; остальные лоты, цены и наличие — на Авито.
- Фотогалерея открывается по ссылке из `SITE_CONFIG.galleryUrl`.

## Настройка ссылок

Откройте `assets/js/config.js`:

```js
export const SITE_CONFIG = {
  phone: "+79312992222",
  avitoProfileUrl: "https://www.avito.ru/brands/i205036214",
  galleryUrl: "https://ellenutelle.gallery.photo/gallery/maksim-kostumy-14rmew/",
};
```

- `phone` — номер для ссылок `tel:` (шапка, меню, контакты, подвал).
- `avitoProfileUrl` — профиль магазина, куда ведут все ссылки на лоты.
- `galleryUrl` — внешняя фотогалерея.

Галерея размечена прямо в `index.html`: каждая фотография — `figure.gallery__item` с кнопкой `gallery__btn` и картинкой внутри. Синхронизации с Авито и автоподтягивания цен нет.

## Юридический блок

В подвале всех страниц: копирайт, оговорка о публичной оферте, цены в рублях, адрес, часы, телефон и ссылки на политику и сведения о продавце. `privacy.html` описывает обработку данных по 152-ФЗ. Реквизиты ИП (ФИО, ОГРНИП, ИНН) нужно добавить после подтверждения владельцем.

## Работа с изображениями

- Максимальная ширина кадра 900 px (обрезной `-640` — для телефонов), качество 80, без метаданных.
- Основной файл + уменьшенная копия (`-640`, `-900`, `-1200` и т. п.) подключается через `srcset`.
- Новое фото: положить в `assets/images/`, добавить `-640`-копию и `figure.gallery__item` в галерею `index.html` — размеры `900×1350` для вертикального кадра или `900×600` для горизонтального.
- `og-image.jpg` (1200×630) — превью для ссылок в соцсетях.

## Локальный просмотр

Откройте `index.html` в браузере или запустите сервер из корня репозитория:

```bash
python -m http.server 8000
```

## Публикация на GitHub Pages

**Settings → Pages → Deploy from a branch**, ветка `main`, папка `/ (root)`. Домен и HTTPS настраиваются в том же разделе.
